# 📝 Como usar o Aplicativo no dia a dia

Siga estes passos simples para monitorar seu rebanho:

1.  **Abra o Aplicativo:** Ao entrar, ele vai buscar na internet as informações mais novas das coleiras.
2.  **Olhe o Mapa:** Veja se todos os pontos estão verdes. Se algum estiver vermelho, o aplicativo vai te avisar.
3.  **Verifique um Animal:** Se quiser saber de um búfalo específico, procure pelo número da etiqueta dele na lista.
4.  **Cuidado com as Fugas:** Se o animal sair do limite que a gente combinou (a **Cerca Virtual**), o celular vai apitar. Use o mapa para ver para que lado ele foi.
