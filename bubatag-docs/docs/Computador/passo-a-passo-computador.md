# 🛠️ Como gerenciar sua fazenda pelo computador

1.  **Veja o Painel Principal (Dashboard):** Logo de cara, você verá quantos animais estão sendo monitorados e a temperatura média de todos eles.
2.  **Analise os Desenhos (Gráficos):** Se a linha vermelha (temperatura) estiver muito alta, talvez seja hora de levar os animais para um lugar com mais sombra ou água.
3.  **Cadastre Novos Animais:** Quando comprar um búfalo novo, é aqui que você avisa ao sistema qual coleira ele vai usar.
4.  **Confira o Equipamento:** O sistema também te avisa se a bateria de alguma coleira estiver acabando, para você poder trocar antes que ela desligue.
