# 🖥️ Conhecendo o Painel do Computador

O painel no computador ajuda você a entender o comportamento do rebanho ao longo do tempo e a cuidar dos equipamentos.

### Avisos e Alertas
O sistema organiza os avisos para você não se perder:

1.  **Alertas de Saúde (Vermelho):** Mostra quais búfalos sentem mais calor e em quais horários o estresse térmico é maior.
2.  **Alertas de Localização (Amarelo):** Registra as vezes que os animais saíram da área permitida. Isso ajuda a saber se tem algum buraco na cerca física.
3.  **Manutenção (Branco):** Lista de quais coleiras pararam de funcionar (ficaram "em branco"), para que você possa verificar o equipamento.
